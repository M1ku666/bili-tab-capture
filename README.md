# BiliTabCapture

将本地或哔哩哔哩的动态谱视频转换为PDF文件

相比[TabCapture](https://github.com/santiRostan/TabCapture)新增以下功能：

- 方便地拖拽上传本地文件
- 从哔哩哔哩视频转换，登录哔哩哔哩账号获取更高分辨率视频
- 手动水平裁切或删去截图，去除识别效果不好的重复部分
- 图像反色，去除彩色背景，自定义字体及背景颜色
- 页边距，图片间距设置
- 纸张横竖方向设置
- 标题不再独占一页，且支持非英文字符
- 更方便的视频时间裁切及预览

## 声明

仅供学习与练习使用，若UP主提供谱面购买链接请勿使用本工具，尊重辛苦扒谱劳动成果

登录由[bilix](https://github.com/Koril33/bilix)处理，风险与本项目无关



使用到的开源项目：

- [TabCapture](https://github.com/santiRostan/TabCapture)
- [bilix](https://github.com/Koril33/bilix)


## 配置

环境配置请参照[TabCapture](https://github.com/santiRostan/TabCapture)

打包exe请运行build_exe.bat，产物在 dist/BiliTabCapture.exe
